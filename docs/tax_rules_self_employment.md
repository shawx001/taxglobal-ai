# 税务规则参考 — 自雇(Self-Employment)完整税款

日期：2026-06-02
性质：税务知识/规则参考(将来 Step 6 知识库的素材;也用于诚实设计自雇前端模块)
范围：美国联邦 + 州,2025 税年,个人(独资/独立承包人/单成员 LLC)
所有数值已核实官方来源(见文末)。

---

## 0. 一句话结论

**自雇收入被两层联邦税打击,再加州税——三者叠加:**
1. **SE 税(自雇税)** = 你既是雇主又是雇员,要自己交全部的社保+医保(本来雇主帮你出一半)。
2. **联邦所得税** = 净利润扣除若干项后,仍按普通累进税率交所得税。
3. **州所得税** = 净利润同样进州税。

**SE 税不是替代所得税,是额外的。** "交了 15.3% 就完了"是常见误解——错。

---

## 1. 全部税款项(逐条 + 税率 + 法条)

### ① SE 税(Self-Employment Tax,IRC §1401)
社保 + 医保部分,自雇者自付全额:
- **税基 = 净利润 × 92.35%**(`net earnings from self-employment`;92.35% 抵掉雇主等价部分)
- **社保 12.4%**,封顶在社保工资基数 **$176,100(2025)**
- **医保 2.9%**,**无上限**(所有净earnings)
- → 合计 **15.3%** 到 $176,100,之上 2.9%
- **附加医保 0.9%**:净earnings(与工资合并)超过申报身份阈值(single $200k / MFJ $250k / MFS $125k)的部分(IRC §1401(b)(2),Form 8959)
- 来源:IRS《Self-Employment Tax》、Topic 554/560、Pub 15-A

### ② 联邦所得税(IRC §1)—— 有,而且是大头
净利润**也是普通收入**,按累进税率(10%–37%)交。但在算所得税前,有几项扣除把应税额降下来:

| 扣除项 | 法条 | 说明 |
|---|---|---|
| **½ SE 税** | §164(f) | SE 税(§1401 部分,不含附加医保)的一半,above-the-line 减 AGI |
| **QBI 合格经营收入扣除** | §199A | 最高 **20% × 合格经营收入**;**只减所得税、不减 SE 税**;QBI 在减完 ½ SE 税后的净经营收入上算。2025 应税收入阈值 **$197,300 单 / $394,600 MFJ**,超过后进入 W-2 工资限制 + SSTB(特定服务业)逐步剔除,phase-out 窗口 $50k 单 / $100k MFJ(上限 $247,300 / $494,600)。本规则参考只固化 2025 税年数据；适用税年表述以已归档 IRS QBI 页面为准。 |
| **自雇健保扣除** | §162(l) | 自付健康保险费可 above-the-line 扣 |
| **自雇退休供款** | §404/§408(k) 等 | SEP-IRA / Solo 401(k) 供款可扣 |
| **标准或分项扣除** | §63 | 适用于整体应税收入 |

→ 净利润 − 上述扣除 = 应税收入,按联邦累进档计税。

### ③ 州所得税
净利润同样进**州所得税**(按各州规则;如 CA/NY 累进、IL/CO/GA 平税、TX/FL/WA/NV 零税)。

### ④ NIIT(净投资收益税 3.8%)—— **不适用**
NIIT 针对**被动净投资收益**;**积极自雇经营收入不属于 NII,不缴 NIIT**。(别和资本利得/crypto 那块混了。)

### ⑤ 季度预缴(IRC §6654)
自雇没有雇主代扣,必须**按季预缴**(覆盖 SE 税 + 所得税),否则有罚息。常见近似:全年总税额 / 4。

## 2. 计算顺序(怎么串起来)

```
净利润 (net profit = 收入 − 经营费用)
  │
  ├─[A] SE 税:  base = 净利润×0.9235
  │             SE税 = min(base,176100)×12.4% + base×2.9% (+附加医保 0.9% 超阈值)
  │
  └─[B] 所得税: AGI 起点 = 净利润
                 − ½ SE税 (§164(f))
                 − 自雇健保 (§162(l))  − 退休供款 (SEP/Solo401k)
                 = 调整后
                 − QBI 20% (§199A, 受阈值/限制)
                 − 标准/分项扣除
                 = 应税收入  → 联邦累进档 + 州所得税
  
总税 = [A] SE税 + [B] 联邦所得税 + 州所得税      （NIIT 不计）
季度预缴 ≈ 总税 / 4   (§6654)
```

## 3. 我们引擎的覆盖 vs 缺口(关键)

| 款项 | 引擎现状 |
|---|---|
| SE 税(SS/医保/附加医保/½抵扣额) | ✅ `self_employment_tax` 已有(Step 2.1) |
| 联邦累进所得税 | ✅ `federal_income_tax`(但需把扣除链喂进去) |
| 州所得税 | ✅ `state_income_tax`(CA/NY 等已可算) |
| **QBI §199A 20% 扣除** | ❌ **没有**(影响所得税,缺它会**高估**自雇者所得税) |
| 自雇健保 / 退休供款扣除 | ❌ 没有(目前靠用户手填一个 SEP 数) |
| **把 SE税+所得税+州税+各扣除串成"自雇总税"** | ❌ 没有(`income_tax_summary` 仍 ⬜) |
| 季度预缴金额 | ❌ 没有(可由总税/4 派生) |
| NIIT 对自雇 | ✅ 正确——不适用,不应计 |

**结论:我们能可靠算"自雇 SE 税";但"自雇要交的总税"目前算不全**——缺 QBI、健保/退休扣除、以及把各块串起来的合并计税。所以**不能在前端展示一个"自雇总税额"假装完整**。

## 4. 对自雇前端步骤(Step 5.4)的含义(诚实设计)

- **能可靠做**:SE 税面板调 `/calc/self-employment`,显示 SE 税(社保/医保/附加医保)+ ½ 抵扣额 + 法条。
- **不能假装**:不要再像原型那样在前端拼一个"总税额(SE税 + 联邦 + CA州税)"——那既用了过时硬编码 `caStateTax`(REQ-003),又**漏了 QBI 等扣除**,会误导。
- **诚实呈现**:SE 税给准;所得税部分提示"净利润(减 ½ SE 税后)还要并入普通收入算所得税 + 州税;**QBI(最高 20%)等扣除尚未建模,完整自雇总税待 `income_tax_summary` + QBI 引擎**"。
