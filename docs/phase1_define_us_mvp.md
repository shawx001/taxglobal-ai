## 1. 立项一句话（Why）

> 做全球第一个"AI 原生 + 多身份 + 每条结论附法条可审计"的税务计算与合规平台；MVP 先把**美国**做深做实、可本地跑、可测试、可追溯。

商业理由（摘自 PRD §1）：现有工具（TurboTax/TaxJar/Avalara）默认"住美国、单一收入、不搬家"，在 Remote Work + 多元收入（RSU/自雇/加密/跨境电商）下假设全部过时；且只给数字不给法条、无法审计。

北极星指标（项目计划书）：**每月由平台主动识别并被用户采纳的"可执行节税/合规行动"数量**——不是算了多少次税，而是真省了多少钱、避了多少罚款。

## 2. 范围与非目标（Scope / Non-Goals）

### 2.1 MVP 范围（U.S.-first，In Scope）
- 多身份合并计税：W-2 / RSU / 自雇 / 加密 / 跨境电商。
- 美国联邦所得税 + FICA（含附加医保税）+ 分州所得税。
- FEIE 基础估算、加密成本基估算、电商 Nexus 估算。
- 知识库驱动的提醒 + Copilot 回答，**每条结论附法条来源**。
- 所有金额来自计算引擎；所有建议来自知识库；规则可版本化、可回溯。

### 2.2 非目标（本期不做，摘自 PRD §2.2 + 计划书暂缓项）
- 自动 E-File、欧盟/英国 VAT 申报、企业税务完整模块（仅占位）。
- 自有模型训练 / LoRA / vLLM、全国际深度覆盖、真 OCR/VLM。
- 真 Google/Apple/微信/Shopify/Amazon OAuth（先 mock）。
- **不取代税务师**：复杂跨境只给信息与引导，不构成正式税务/法律意见。

### 2.3 合规红线（税务产品特有，必须贯穿全流程）
- 不确定规则不得伪装为确定结论（标 estimate/demo/unverified）。
- 知识库未覆盖必须明示"暂无覆盖"，不得编造税率/法条/日期。
- 每个税务结论可追溯到 `knowledge_id / rule_version / source_url / effective_date`。
